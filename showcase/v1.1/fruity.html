Changelog

1.1.1

  • Added a sliding selection highlight to single-row tabs while preserving the existing markup and keyboard controls.
  • Added a dialog layout with a scrolling body and a visible header and footer.
  • Added reuse instructions and an interactive long-dialog example.

1.1.0

  • Added a glass dropdown with keyboard navigation and a native select as its value source.
  • Added saturation and value controls, a hue slider, and larger swatches and compact color chips.
  • Added a glass scrollbar and a translucent variant of the existing disclosure header.
  • Added an inline error box, action notice, status strip, field dividers, contrast samples, and destructive button styles.
  • Kept the 1.0 components and file workflow examples, and archived the original 1.0 showcase.
