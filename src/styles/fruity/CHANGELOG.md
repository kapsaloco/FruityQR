# FruityUI changelog

## 1.1.1

- Added a sliding selection highlight to the existing tab list when using the
  v1.1 initializer. The highlight switches instantly with reduced motion.
  Wrapped tabs and forced-colors mode retain the selected button style.
- Added `fr-dialog--scroll-body` to keep dialog headers and actions in view
  while the body scrolls. It can be combined with `fr-glass-scrollbar`.
- Added a scrolling Help & About example and updated the reuse instructions.

## 1.1.0

- Added glass dropdowns backed by native selects and reusable saturation, value,
  and hue controls.
- Added color swatches and chips, contrast samples, glass scrollbars and
  disclosures, field errors, action notices, status strips, field dividers,
  and destructive button variants.
- Retained the 1.0 foundation and its archived component and file workflow
  showcases.

## 1.0.0

- Introduced the FruityHash foundation with the window shell, glass panels,
  buttons, forms, tabs, dialogs, tooltips, and file workflow components.
